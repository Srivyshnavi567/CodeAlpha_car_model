Car Price Prediction

Description:

This project uses Machine Learning to predict car prices using Linear Regression in Python.

Technologies Used:

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Features:

- Data preprocessing
- Label encoding
- Feature engineering
- Model training and prediction
- Model evaluation using MAE, MSE, RMSE, and R2 Score
- Data visualization

How to Run:

1. Install required libraries
2. Run the Python file

Output:

- Predicted Car Prices
- Model Evaluation Metrics
- Actual vs Predicted Price Graph
